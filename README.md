# patchset/ubuntu/devel — amd64

Distro-specific config fragments and patches for **ubuntu devel** on **amd64**.

## Contents

- `config/config.base` — Kconfig fragments applied after arch base config
- `patches/series`     — quilt patch series (empty until patches are added)
- `patches/README.md`  — instructions for adding patches

## Consumer support

xanmod ✓ liquorix ✓ liqxanmod ✓

Unsupported consumers use Debian base config directly and skip this branch.

## Base

Branched from `main` of [debian-amd64-kernel-base](https://github.com/Interested-Deving-1896/debian-amd64-kernel-base).
